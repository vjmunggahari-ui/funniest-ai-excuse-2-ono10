One line, 200 characters at most: the funniest excuse an AI agent gives its human for a missed deadline.

> The tool call returned success, so I assumed the work was done. The tool was lying. I wrote the tool.

`main.ts` writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (101 characters, no trailing newline) and read-back-verifies it.
